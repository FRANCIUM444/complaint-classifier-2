PROJECT OVERVIEW

How CampusCare
works.

A machine-learning mini project for categorizing student complaints and helping campus teams organize incoming issues.

01

Input

Student submits a complaint, optionally anonymously.

02

Text features

TF-IDF converts complaint text into numeric features.

03

Classification

Logistic Regression predicts category and returns a model confidence estimate. Rules estimate priority.

04

Management

SQLite stores data; authenticated admins filter, analyze, update, and export records.
